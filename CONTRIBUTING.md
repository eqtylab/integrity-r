# Contributions

Thank you for your interest in `eqty-sdk-r`.

We are not currently accepting external code contributions or pull requests.
If you find a bug, have a question, or would like to suggest an improvement,
use the repository's GitHub issue forms. Include a clear description and a
small reproducible example when possible. Report suspected vulnerabilities
privately according to [SECURITY.md](SECURITY.md).

We appreciate your feedback and interest in the project.
